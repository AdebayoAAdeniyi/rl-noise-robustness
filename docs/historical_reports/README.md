# The submitted report

`CMPUT655_project_report.pdf` is our project report, "What Hinders
Reinforcement Learning More: Action Noise, Observation Noise, or Reward
Noise?", joint work with Isaiah Heidt.

Figures 1 to 6 in the main body are built from expected return and are
unaffected by the logging defect described in [../FINDINGS.md](../FINDINGS.md).
Appendix A discusses the critic delta signal alongside the actor and critic
parameter variances; the variance discussion is sound and the delta discussion
is not. FINDINGS.md sets out exactly what is affected and why.
